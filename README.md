# One-Sentence Absurd Invention Pitch

Entry for the make.fun bounty
[u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

`main.py` (pure Python standard library) writes one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance — a washing machine with a grudge against missing socks — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
